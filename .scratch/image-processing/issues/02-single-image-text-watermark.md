# 02 — 单图文字水印与图片/PDF 导出

**What to build:** 用户可在单张源图片预览中配置文字水印，实时确认效果，并导出水印图片或水印 PDF；所有导出仍只在浏览器本地完成。

**Blocked by:** 01 — 初始化本地图像处理站点与单图原图 PDF。

**Status:** done

- [x] 用户可配置文字水印内容、字号、颜色、不透明度、旋转角度；字体为系统无衬线字体。
- [x] 用户可自由拖拽水印位置；旋转后文字完整位于源图片内，预览与导出结果一致。
- [x] 用户可启用重复水印，看到固定网格密度覆盖整图；配置保留水平、垂直间距字段，但首版不提供间距控件。
- [x] 用户可导出 PNG、JPEG、WebP 水印图片，或导出无白边、页面比例匹配的水印 PDF；导出名称遵循命名规则。
- [x] Vitest 验证水印边界、相对位置、重复配置与导出规则；Playwright 验证单图配置、拖拽、预览和各导出入口的用户可见结果。

## Comments

- 验证：`npm run test:all` 通过（Vitest 8 项；Playwright 8 项通过、2 项按端跳过；生产构建通过）。
- 预览、图片导出、PDF 导出共用 Canvas 水印渲染路径；旋转文字位置按旋转后外接范围限制在源图片内。
