# 03 — 桌面批量原图 PDF ZIP

**What to build:** 桌面用户可选择多张源图片、在缩略图列表中检查当前图，并一次下载按选择顺序生成的一图一 PDF ZIP；移动端仍不出现批量入口。

**Blocked by:** 01 — 初始化本地图像处理站点与单图原图 PDF。

**Status:** done

- [x] 桌面用户可多选可处理源图片，浏览缩略图并切换当前预览图；无效图片不会污染有效处理会话。
- [x] 用户可发起桌面批量原图 PDF 导出；每张源图片对应独立 PDF，顺序与选择顺序一致，结果下载为一个 ZIP。
- [x] 重复基础名自动编号，ZIP 中文件名清晰且不冲突。
- [x] 移动视口保持单选、单图导出边界，不提供桌面批量交互。
- [x] Vitest 验证批量顺序、命名与 ZIP 内容规则；Playwright 验证桌面多选、缩略图切换、ZIP 导出和移动端限制。
